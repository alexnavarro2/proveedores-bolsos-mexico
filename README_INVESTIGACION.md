# Investigación de proveedores de bolsos en México

Fecha de corte: 7 de octubre de 2026.

## Metodología
Se priorizaron fabricantes, maquiladores y mayoristas mexicanos de bolsos para dama, con atención especial a León, Guanajuato. La búsqueda combinó sitios oficiales, directorios sectoriales, registros empresariales públicos y marketplaces. Se distinguieron proveedores comercialmente accionables de candidatos industriales que requieren una segunda verificación.

## Niveles
- A: fabricante mexicano / taller fabricante.
- B: fabricante-maquilador u OEM potencial.
- C: mayorista/comercializador mexicano.
- D: importador/distribuidor (ninguno priorizado en esta primera edición).

## Score
Score preliminar 0-100 basado en similitud de producto, fabricación mexicana, mayoreo, personalización/private label, presencia digital, contacto e información pública. Los campos no publicados se dejan como `No confirmado` o `Consultar directamente con proveedor`.

## Limitaciones
No todos los talleres cuentan con sitio web; varias unidades identificadas mediante registros de actividad económica requieren llamada o visita para confirmar catálogo, MOQ, capacidad, private label y vigencia. No se deben interpretar las capacidades no publicadas como confirmadas.
